DessinTel

Le téléphone arabe en dessins : une phrase devient un dessin, qui redevient une phrase… et on découvre le résultat tous ensemble.

🙋 Je joue

Le plus simple : scanne le QR code affiché par le maître du jeu.

🎩 J’anime

Créer une partie ↩️ Reprendre la partie 📺 Ouvrir l’écran TV (optionnel)
Comment ça marche ?
  1. Le maître du jeu crée une partie : un code et un QR code s’affichent. Il peut jouer aussi.
  2. Chacun écrit une phrase dans son carnet (ou tire une idée au hasard 🎲).
  3. Les carnets tournent : tu dessines la phrase du voisin, le suivant devine ton dessin, puis le suivant dessine sa réponse…
  4. Quand chaque carnet a fait le tour, on les rejoue page par page, sur les téléphones et sur la TV. Fous rires garantis.
  5. Pour finir, on vote : 🎨 plus beau dessin, 😂 plus drôle, 🕵️ meilleur pour deviner.

De 3 à 16 joueurs, un téléphone chacun. Personne n’attend : tout le monde joue en même temps.

🧪 Mode local : les onglets de ce navigateur jouent entre eux (pour tester).
